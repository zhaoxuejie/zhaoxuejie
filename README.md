### 在做什么

企业不缺模型 API，缺的是业务知识怎么沉淀、规则怎么进系统、异常怎么兜底。这几年只做这件事，并把过程摊开写下来。

- **Agent 工程化** —— 不依赖 Agent 框架，用 29 个可运行阶段从零手写运行循环、工具调用、MCP、记忆与技能
- **可核验的 RAG** —— 检索 + 证据门 + 引用校验，每条结论都点得回原文，资料里没有的就明说没有
- **AI 工程规范** —— 文档闸门 + 增量任务卡 + 版本快照，把 AI 协作开发的流程锁死，抑制需求漂移
- **DSH 插件生态** —— 工具安全守卫、Obsidian 长期记忆、学术文献检索、会话复盘导出等开源插件
