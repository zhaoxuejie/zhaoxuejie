### 在做什么

企业不缺模型 API，卡在「敢不敢用」：业务知识怎么沉淀进系统、规则怎么变成智能体能执行的流程、出了异常谁兜底。这几年只做这一件事，并把过程摊开写下来。

- **业务知识进系统** —— 把散在老师傅脑子里的经验、手册与工单，拆成智能体能执行的流程与知识库
- **答案可核对** —— 检索 + 证据门 + 引用校验，每条结论点得回原文，资料里没有的就明说没有
- **异常有人兜底** —— 危险命令拦截、路径白名单、敏感文件黑名单、人工审批与审计留痕
- **流程不漂移** —— 文档闸门 + 增量任务卡 + 版本快照，把 AI 协作开发的流程锁死
